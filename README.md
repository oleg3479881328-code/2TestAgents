# Project Execution OS

Universal document-first Project Execution OS.

This repository is the source of truth for building a minimal reusable workflow system that can guide any project from raw input to reviewed result and reusable knowledge extraction.

## Core Boundary

This project is not only an AI Skill System, not only an agent framework, not only an orchestration engine, and not only a Codex workflow.

Project Execution OS is the upper-level system.
AI Skill System is one subsystem.

## Current Mode

Document-first foundation.

No runtime engine.
No orchestration engine.
No backend.
No frontend.
No vector database.
No semantic search.
No automation framework.
No mass agent creation.
No mass skill creation.
No Codex execution layer.

## Universal Execution Loop

INPUT
→ clarification
→ research
→ planning
→ execution spec
→ review
→ result
→ extract reusable knowledge
→ log

## First Goal

Create and stabilize the Universal Workflow Contract v1 before building any runtime, automation, or specialized execution system.
