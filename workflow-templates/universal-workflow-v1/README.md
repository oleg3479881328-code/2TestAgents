# Universal Workflow Template v1

## Purpose

Reusable template for running any project through the Project Execution OS document-first workflow.

Use this template when starting a new project workflow run.

## Template Chain

```text
00_INPUT.md
01_CLARIFICATION.md
02_RESEARCH.md
03_PLAN.md
04_EXECUTION_SPEC.md
05_REVIEW.md
06_RESULT.md
07_KNOWLEDGE_EXTRACT.md
08_LOG.md
```

## Usage Rule

Copy this template folder into:

```text
workflow-runs/<run-id>/
```

Then fill the files in order.

## Current Boundary

This template is document-first.

No runtime, backend, frontend, automation, orchestration engine, vector database, or Codex execution is required to use it.
