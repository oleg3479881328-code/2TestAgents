# 04_EXECUTION_SPEC — Foundation Review

## Workflow Run

`0001-foundation-review`

## Execution Spec Purpose

Define the exact manual review work required for the Project Execution OS foundation.

## Work To Execute

Manually inspect the current foundation artifacts:

- `README.md`
- `PROJECT_INDEX.md`
- `docs/WORKFLOW_CONTRACT.md`
- `docs/GOVERNANCE.md`
- `docs/REVIEW_PROCESS.md`
- `docs/LIFECYCLE.md`
- `logs/WORKFLOW_LOG.md`
- `knowledge-library/README.md`

## Review Questions

1. Do the documents describe the same project?
2. Is Project Execution OS clearly above AI Skill System?
3. Is the universal workflow chain clear and minimal?
4. Are runtime, automation, backend, frontend, vector DB, and orchestration correctly forbidden for now?
5. Is state separation explicit enough?
6. Is review before activation enforced?
7. Is knowledge extraction defined clearly enough?
8. Is logging sufficient to prevent drift?
9. Is the next action clear?
10. Is anything overbuilt for the current phase?

## Required Output

The review must produce:

- pass/fail/partial checklist;
- strengths;
- weaknesses;
- required improvements;
- activation decision;
- next required action.

## Non-Goals

Do not create code.
Do not create runtime.
Do not create automation.
Do not create new specialized agents.
Do not create new AI skills.

## Completion Criteria

This stage is complete when `05_REVIEW.md` exists and gives a clear decision on the foundation state.
